# eleicao-2026-data

Release-only repo hosting the TSE 2026 site database (`tse2026_site.duckdb`) as a GitHub Release asset, consumed by the website at https://github.com/bad-noodles/eleicao-2026 (local, not yet pushed).

No source code lives here — see `website/scripts/build-site-db.mjs` and `website/scripts/upload-duckdb.mjs` in the main project for how this data is built and published.
